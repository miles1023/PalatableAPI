# intake/processed/

Files from intake/raw/ that are currently being parsed into findings.

## Rules

- Move a file here from raw/ when you begin processing it.
- Parse it into findings and add those to findings/ or the appropriate system/ subfolder.
- When a file is fully processed, delete it or move it out of the active area.
- If processing is interrupted mid-session, leave the file here with a note at the top.
