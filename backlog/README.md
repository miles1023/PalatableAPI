# backlog/

Triage area for items that need attention but have not been prioritized.

## Purpose

Anything that:
- Needs to be done but is not the current focus
- Was noticed during a session but not investigated
- Is a good idea for a future session
- Is a dependency that is blocking something else

## Review cadence

Review at the start of each session. Promote items to active work or leave them here for later.

## File naming

`YYYY-MM-DD-brief-description.md`

## Current backlog

Items will be added here as they are discovered. The initial RE session priorities are in `NEXT_SESSION.md`.
