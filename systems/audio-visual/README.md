# systems/audio-visual/

Cosmetic assets: models, textures, audio, UI, animations.

## What this system covers

- Character and Pal models
- Textures and materials
- Sound effects and music
- UI widgets and layouts
- Animations

## Scope note

This system is NOT a target for reverse engineering of game logic. It is included because PAK mods routinely modify these assets, and the modding surface (PAK asset replacement) is documented here for completeness.

## Access surface

PAK asset replacement only. Use FModel to read existing assets and UnrealPak/repak to create replacement paks.

## What is NOT here

- Any gameplay logic
- Any stat values
- Any runtime state

## Status: KNOWN (PAK surface) — not a RE target
