# sessions/

Session handoff notes. One file per session.

## Purpose

This folder is how knowledge survives between sessions. Every session should end by writing a handoff note. Every session should start by reading the most recent note.

## File format

`YYYY-MM-DD.md`

## What each session file must contain

1. **Date and focus** — What this session was trying to do
2. **Tools used** — Which MCP bridges or manual tools were used
3. **Findings** — What was confirmed or discovered (summarized; full findings go in `findings/`)
4. **Failures** — What was tried and did not work (prevents repeating failed approaches)
5. **Open questions** — What remains unresolved
6. **Next session priorities** — Ordered list of what to do next
