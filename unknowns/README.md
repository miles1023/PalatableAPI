# unknowns/

Unresolved questions and unclassified findings.

## Purpose

This folder is the safety net for the RE process. Anything that:
- Does not have a clear home yet
- Is suspected but not confirmed
- Is a question without an answer
- Is a finding that contradicts a previous finding

...goes here rather than being lost or forced into the wrong category.

## Review cadence

At the start of every session, read through unknowns/ and decide:
- Can any entry be answered with the tools available today?
- Can any entry be assigned to a specific system or surface?
- Is any entry now outdated or resolved by new findings?

## File naming

`YYYY-MM-DD-brief-description.md`

## What does NOT go here

- Findings that are confirmed (go to `findings/` or the relevant `systems/` folder)
- Raw tool output (goes to `intake/raw/`)
- Open questions already tracked in a specific system's README.md (leave them there)
